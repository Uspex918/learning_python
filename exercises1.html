Задание 11

Условие: Пользователь вводит a и b. Посчитайте сколько процентов a от b. Формула процентов (a/b)*100. 

a = float(input("Часть: "))
b = float(input("От целого: "))

# ваш код здесь

a = float(input("Часть: "))
b = float(input("От целого: "))

if b == 0:
    print("На ноль делить нельзя! И части от 0 нет.")
else:
    result = (a / b) * 100
    result = round(result, 2)
    print(str(result) + "%")

Задание 12

Условие: Пользователь вводит не целое число, например 5.2564494 и вводит до какого знака после запятой (точки) его округлить. Сделайте рассчеты. 

num = float(input("Введите число: "))
rounding = int(input("До какого знака округлять: "))

# ваш код здесь

num = float(input("Введите число: "))
rounding = int(input("До какого знака округлять: "))

if rounding < 0:
    print("Значение для количсетва знаков после точки не может быть меньше 0.")
    # Хотя если передать в round отрицательное число в параметр до скольки округлять,
    # то результатом округлеия будет просто 0. Так специально сделано, чтоб ошибок не было.
else:
    print(round(num, rounding))

Задание 14

Условие: Нужно разделить a на b. Если b равняется 0, то выведите сообщение, что на 0 делить нельзя. А если всё ОК, то посчитайте! 

a = float(input("Введите число: "))
b = float(input("Введите 2-е число: "))

# ваш код здесь

a = float(input("Введите число: "))
b = float(input("Введите 2-е число: "))

if b == 0:
    print("На ноль делить нельзя! Даже если очень хочется!")
else:
    print("Результат:", a / b)


# ИЛИ
if b == 0:
    print("На ноль делить нельзя! Даже если очень хочется!")
else:
    result = a / b
    print("Результат:", result)


# ИЛИ
if b == 0:
    print("На ноль делить нельзя! Даже если очень хочется!")
else:
    result = a / b
    print("Результат:", round(result, 2))


# ИЛИ
if b == 0:
    result = "На ноль делить нельзя! Даже если очень хочется!"
else:
    result = round(a / b, 2)

print("Результат:", result)


# ИЛИ другие удобные в данной ситуации варианты, даже так:
if b == 0:
    message = "На ноль делить нельзя! Ошибка операции -"
    result = False

    message = "Результат:"
    result = round(a / b, 2)

Задание 15

Условие: Пользователь вводит Имя и потом отдельно Фамиилию. Давайте попробуем сделать так, что если он введет все правильно, то мы объединим его Имя и Фамилию в одну строку (как один объект новый) и выведем на печать в терминал.
А если он ошибется и введет в поле "Имя" анкеты сразу и свое Имя и Фамилию, то мы выведем сообщение, что:
"Внимательно заполняйте анкету!! Это был последний бланк ахахах)))"
и программа завершиться.
Подсказки:
1) Там будет пробел в строке, если он введет все сразу.
2) Сначала проверяйте ошибочный вариант, так будет проще и правильнее. 

name = input("Введите Имя: ")
last_name = input("Введите Фамилию: ")

# ваш код здесь

name = input("Введите Имя: ")
last_name = input("Введите Фамилию: ")

if " " in name:
    print("Внимательно заполняйте анкету!! Это был последний бланк ахахах)))")
else:
    full_name = name + " " + last_name
    print(full_name)


# или более предусмотрительно с оператором or:
if " " in name:
    print("Внимательно заполняйте анкету!! Это был последний бланк ахахах)))")
elif name == "" or last_name == "":
    print("Бланк нужно заполнить полностью!! (всё заново пока что)")
else:
    full_name = name + " " + last_name
    print(full_name)
