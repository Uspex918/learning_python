Задание 2

Условие: Пользователь вводит строку. Если строка начинается с буквы "A" или "a" — выведите "Начинается с A", иначе — "Начинается с другой буквы". Можно использовать методы строк.

text = input("Введите строку: ")

# ваш код здесь

text = input("Введите строку: ")

if text.startswith("A") or text.startswith("a"):
    print("Начинается с A")
else:
    print("Начинается с другой буквы")


# ИЛИ
if text[0] == "A" or text[0] == "a":
    print("Начинается с A")
else:
    print("Начинается с другой буквы")


# ИЛИ
if text[0].lower() == "a":
    print("Начинается с A")
else:
    print("Начинается с другой буквы")

В результате этого выражения text[0] мы получаем новый объект строки, которая
состоит из 1 символа, и значит мы можем к нему применять методы.

Задание 11

Условие: "Привет - Пока программа"
Если пользователь введет: Привет, привет, приВет или ПРИВЕТ - ответить ему "И тебе Привет!"
Если пользователь введет: Пока, ПоКа, и тд - ответить ему "Адьос!". 

text = input("Введите фразу: ")

# ваш код здесь

text = input("Введите фразу: ")

if text.lower() == "привет":
    print("И тебе привет!")
elif text.lower() == "пока":
    print("Адьос!")
else:
    print("Не, я не разговариваю с незнакомыми людьми! Адьос!")


# ИЛИ более предусмотрительно, чтоб учесть не четкое равенство, а вхождение:
if "привет" in text.lower():
    print("И тебе привет!")
elif "пока" in text.lower():
    print("Адьос!")
else:
    print("Не, я не разговариваю с незнакомыми людьми! Адьос!")

# ВАЖНО!!! предназначение операторов == и in имеет смысл не только с точки зрения эффекта
который мы получаем, а и семантики (значения/предназначения в коде).
Если нам нужно сравнить два символа или две строки на равенство, то мы используем ==,
если вхождение, то in.
Хотя такое: if "привет" in "привет" и даст тот же эффект, что и ==,
нужно брать во внимание, что мы хотим сделать, если четкое совпадение, то используем ==,
если нужно проверить вхождение, то in.
