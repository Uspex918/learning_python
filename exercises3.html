Условие: Найдите сумму всех чисел от 1 до 100 с помощью цикла while.

i = 1
total = 0

# ваш код здесь

while i <= 100:
    total += i

# По этому заданию был вопрос как это работает.
1) Если оказалось, что что-то не понятно - абсолютно нормально пересмотреть лекцию/лекции по циклу.
2) Чтоб наглядно увидеть что происходит, в редакторе поставьте "точку останова" на уровне while,
и в редиме отладки (debug) пошагово проклацайте что происходит (как я показывал), обращайте
особое внимание на то как работают переменные и что происходит. Прям реально погрузитесь в это
заставив себя думать пошагово как то что вы видите.
Чтоб увидеть полную картину, поставьте две точки останова:
1) Одну на уровне while;
2) Вторую на уровне i = 1 (до цикла);
Так вы увидите что сначала БУДУТ СОЗДАНЫ ПЕРЕМЕННЫЕ, а потом они будут менятся внутри
инстукций цикла.
Цикл - это способ исполнить несколько раз один и тот же код (который написан в нем),
чтоб руками не писать многократно одно и то же (если грубо это описать).
Код выше можно записать развернув его без цикла в такой цирк:

total = 0

total += i
total += i
total += i
total += i
total += i
...
total += i
total += i
# и так 100 раз
print("Сумма:", total)

# А если с циклом, то нам понадобиться всего-лишь одна дополнительная переменная i,
которая позволит ограничить условие выполнение цикла, до заданного количества повторов.

Задание 10

Условие: Пользователь вводит число. Подсчитайте, сколько цифр в этом числе. Можно без цикла решить любым способом.

num = int(input("Введите число: "))
count = 0

# ваш код здесь

num = int(input("Введите число: "))
count = 0

if num == 0:
    count = 1
else:
    if num < 0:
        num = -num  # меняем знак на + (- на - = +)

    while num > 0:
        count += 1
        num //= 10

print("Количество цифр:", count)
В примере выше история такая, что мы считаем количество циклов операций целочисленного деления пока в num не получиится 0. Без цикла это выглядит так: 
>>> 56825 // 10
5682
>>> 5682 // 10
568
>>> 568 // 10
56
>>> 56 // 10
5
>>> 5 // 10
0
Или можно посчитать без цикла просто по длине числа как строки: 
num = int(input("Введите число: "))

if num < 0:
    num = -num  # меняем знак на + (- на - = +)

count = len(str(num))
print("Количество цифр:", count)


# или
num = int(input("Введите число: "))

# просто для примера:
if num < 0:
    count = len(str(num)) - 1  # не учитываем знак -
else:
    count = len(str(num))

print("Количество цифр:", count)

text = input("Введите текст: ")
symbol = input("Введите символ который по краям фрагмента текста: ")

start_index = text.index(symbol) + 1 # индекс начала получили

new_text = ""
while start_index < len(text):
    char = text[start_index]  # берем символ из текста

    new_text += char
    start_index += 1

print(new_text)


# ИЛИ только срезами. Внимательно с индексами и промежуточной строкой.
text = input("Введите текст: ")
symbol = input("Введите символ который по краям фрагмента текста: ")

start = text.index(symbol) + 1 # индекс начала получили

# давайте сразу срежем с этого момента до конца текста:
part = text[start:] # срез с start до конца

 т

    print(for_print)
    index += 1

index = 0

    for_print = text[index].rjust(index+1, " ")
    print(for_print)
    index += 1


# ступеньки наоборот:
text = text[::-1]
index = 0
while index < len(text):
    for_print = text[index].rjust(len(text) - index, " ")
    print(for_print)
    index += 1

Задание 14

Условие: Есть перечень знаков пунктуации и спец. символов:
punctuation = "!@#$%^&./,?|"
И есть строка текста, в котрой они могут присутствовать.
Сформируйте новую строку без знаков пунктуации, оставив только текст, пробелы сохранить. Так нужно вот и всё. 

punctuation = "!@#$%^&./,?|"
text = "Наверно на этом упражнении закончим. Хватит! Мы хотим отдыхать! #@&#@&!!!"

# ваш код здесь

punctuation = "!@#$%^&./,?|"
text = "Наверно на этом упражнении закончим. Хватит! Мы хотим отдыхать! #@&#@&!!!"


new_text = ""

idx = 0
while idx < len(text):
    char = text[idx]
    if char not in punctuation:
        new_text += char
    idx += 1
else:
    text = text.strip()  # почистим от пробелов по бокам. Только по бокам.

print(new_text)
